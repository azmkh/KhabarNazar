# Data (not in git)

Put these here locally. `.gitignore` keeps them out of the repository.

- `khabarnazar_roman_urdu_dataset.csv`: the full 8,267-row dataset
- `splits/train.csv`, `splits/val.csv`, `splits/test.csv`: made by `notebooks/01_make_splits.ipynb`

The text comes from Bend the Truth, FIRE 2021, Ax-to-Grind and Hook and Bait. Don't upload it publicly until the original authors allow it. `../outputs/split_ids.csv` records which id is in which split.
